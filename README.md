# Cosmic Merge

A physics merge-and-drop puzzle game in a single HTML file, with no build step and no dependencies.

## Play

Open `index.html` in any browser (desktop or mobile).

- **Aim:** move the mouse or your finger, or use ←/→ (A/D)
- **Drop:** click, tap, or press Space
- When two bodies of the same kind touch, they merge into the next one up:
  Stardust → Asteroid → Moon → Mercury → Mars → Venus → Earth → Neptune → Saturn → Jupiter → Sun
- Two Suns merging make a **Supernova** (+100 bonus).
- If anything stays above the dashed line for too long, the game is over.

Your best score is saved in the browser.
